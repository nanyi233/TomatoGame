# 🍅 番茄工作法游戏 - Pomodoro Timer

一个功能丰富的游戏化番茄工作法应用，帮助你提高专注力和工作效率。

## ✨ 核心功能

### 🕐 番茄计时器
- 标准番茄工作周期（25分钟工作 + 5分钟休息）
- 长休息机制（每4个番茄后15分钟长休息）
- 圆形进度条动画显示
- 精确计时，支持后台运行

### 📋 任务管理
- 创建、编辑、删除任务
- 设置预估番茄数
- 实时追踪任务进度
- 拖拽排序（待实现）

### 🎮 游戏化激励
- 连击奖励系统
- 12个成就徽章可解锁
- 每日/每周目标挑战
- 专注统计排行

### 🎨 视觉效果
- 动态番茄计时器动画
- 工作/休息状态主题色切换
- 完成番茄庆祝动画（彩纸特效）
- 4种主题可选（默认/自然/暗黑/海洋）

### 🔊 音效系统
- 计时器滴答声（可选）
- 番茄完成提示音
- 休息结束提醒音
- 成就解锁音效
- 音量调节控制

### 📊 数据统计
- 每日/每周/每月番茄统计
- 专注时间热力图
- 小时分布图表
- 任务完成率分析

## 🚀 快速开始

### 方式一：直接打开
双击 `index.html` 文件即可在浏览器中运行。

### 方式二：本地服务器
```bash
# 使用 Python
python -m http.server 8080

# 使用 Node.js
npx serve .

# 使用 VS Code Live Server 插件
```

然后访问 `http://localhost:8080`

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Space` | 开始/暂停计时器 |
| `R` | 重置计时器 |
| `S` | 跳过当前阶段 |
| `Esc` | 关闭弹窗 |

## 🏆 成就系统

| 成就 | 描述 | 条件 |
|------|------|------|
| 🍅 第一个番茄 | 完成你的第一个番茄 | 完成1个番茄 |
| 🔥 五连击 | 连续完成5个番茄 | 连击达到5 |
| 💥 十连击大师 | 连续完成10个番茄 | 连击达到10 |
| 🦸 日常英雄 | 一天完成8个番茄 | 单日完成8个 |
| 🧠 超级专注 | 一天完成12个番茄 | 单日完成12个 |
| 💯 百番达成 | 累计完成100个番茄 | 总计100个 |
| ✅ 任务大师 | 完成10个任务 | 完成10个任务 |
| 🗓️ 周战士 | 连续7天使用番茄钟 | 连续使用7天 |
| 🐦 早起鸟 | 在早上6点前开始番茄 | 6点前开始 |
| 🦉 夜猫子 | 在凌晨12点后完成番茄 | 0-5点完成 |
| 🏃 马拉松 | 累计专注时间超过24小时 | 1440分钟 |
| 👑 传奇 | 累计完成500个番茄 | 总计500个 |

- **AudioModule**: 音效控制
- **UIModule**: 界面渲染

- 高效内存管理
